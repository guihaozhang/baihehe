# 拜贺贺 · 照生拜

> 潮汕民俗文化整理工具。查「今天拜什么、买什么、怎么拜」，帮年轻人和海外潮汕人照着长辈的样子拜贺贺。

这是一个**纯静态、无后端**的 PWA：所有数据都在浏览器本地（localStorage），不上传任何个人信息，也不做求签、占卜、算命或付费祈福。内容定位是民俗文化整理，各地习俗以本地长辈说法为准。

## 功能

- **地区引导**：首次进入先选地区（汕头 / 潮州 / 揭阳 / 潮阳 / 澄海 / 普宁 / 海外），按地区显示对应习俗
- **今日结论**：查任意日期的农历、节日、当天该拜谁；「非必拜」的民间说法会明确标注，不误导
- **买什么 / 怎么拜**：24 个节点的供品清单与步骤；清单一次列全，可省的条目打「可省」标签
- **我家拜法**：全局 / 分类 / 节点三级继承，点选即可记录自家规矩，可导出备份
- **开口怎么念**：按长辈口传整理的五步念词模板，选性别婚否自动带入自称，一键复制
- **人设卡**：6 道题生成 12 种 Q 版「拜拜人设」，纯娱乐
- **分享卡**：Canvas 生成家族分工卡与人设卡，可保存图片
- **海外模式**：买不到的供品给替代方案
- **离线可用**：Service Worker 预缓存，断网也能查

## 本地运行

任意静态文件服务器即可，无需构建步骤：

```bash
python -m http.server 8099
```

然后打开 <http://localhost:8099>。首次进入会先选地区；想直接看某天，可在地址后加 `?date=2026-02-16`。

## 技术栈

- 原生 HTML / CSS / JavaScript，无框架、无构建
- [lunar-javascript](https://github.com/6tail/lunar-javascript) 做农历与节日换算
- qrcodejs 生成二维码
- Canvas 生成分享卡 / 人设卡
- Service Worker 做离线缓存（代码 network-first，图片 cache-first）
- localStorage 持久化用户设置与家族规矩

## 内容说明

- 数据均为民俗文化整理，来源包括公开资料与长辈口传；**各地各乡拜法不同，一切以本地长辈说法为准**。
- 「初三拜妈祖、初四拜财神」等属民间顺口溜，非家家户户硬规矩，页面标注为「非必拜」。
- 除夕按定义为腊月最后一天，一年仅一次。
- 不涉及任何求签、掷筊、占卜、算命、祈福交易或导流法事。
